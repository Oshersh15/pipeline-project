# Installation Guide

This project is a Maya pipeline tool written in Python. It is designed to run inside Autodesk Maya.

## Requirements

- Autodesk Maya
- Python available through Maya
- PySide2 or PySide6
- Maya USD plugin enabled
- Maya OBJ export plugin enabled
